Welcome to Vexa!

Vexa is a hobby operating system for x86-64 PCs, written from scratch. It has its own kernel, its own C library and its own desktop with apps, and it runs Linux programs on the side: bash, Python, X11 and GTK 3. It boots from a CD image with BIOS or UEFI, in a virtual machine or on a real PC, and now installs itself on a disk.

Features

  • A real desktop: windows, a menu, search, notifications, snapping and Alt+Tab
  • Apps: Terminal, Files, Text Editor, Settings, Paint, Calculator, Device Manager and more
  • Doom! Chocolate Doom with Freedoom, built with the Vexa SDK NEW
  • Linux programs: bash, coreutils, Python 3.12, curl with HTTPS, X11, GTK 3, OpenGL
  • Hardware: SATA, NVMe, USB 1 to 3, sound, Intel and Realtek network cards NEW
  • Installs on a disk, and keeps your files and settings
  • An SDK with SDL 2 and SDL_mixer, to build your own apps on Linux

Try it in 30 seconds

Download the ISO, then start it in QEMU:

qemu-system-x86_64 -M q35 -m 2G -cdrom vexa.iso

At the prompt, type desktop. Or install it: Install Vexa in the menu.
